## 3. How v4 is built

```
nikah/v4/
  index.html   all markup + CSS (one <style> block, sections in page order)
  i18n.js      ID/EN strings (STRINGS.id / STRINGS.en), data-i18n / data-i18n-placeholder,
               ?to= guest name, locale auto-detect (Indonesia → ID, else EN), localStorage 'nikah_locale'
  app.js       cover open, reveal observer, birds, falling leaves, countdown, Google Calendar link,
               copy account number, lightbox
  rsvp.js      Firebase (project rendezvous-now): writes `wishes` {name, attending, guests, message,
               source:'v4', submitted_at} and `rsvp_contacts` {name, phone, …} (only if phone given);
               live-reads `wishes` for the guestbook + counts
  assets/      v4-only images (WebP)
  HANDOFF.md   this file
nikah/tools/
  prep_assets.py   raw PNG → trimmed, de-fringed WebP (+ contact sheet)
  screens.py       phone + desktop scroll screenshots, prints console errors / 404s
```

**Cache busting:** scripts are loaded as `i18n.js?v=20261102a` etc. GitHub Pages caches for
about 10 minutes. When you change a JS file, bump the `?v=` on its `<script>` tag. Images aren't
versioned, so **use a new file name** when replacing an image whose name already exists on the live site.

**Reveal system (mirrors the sample's entrance effects):** any element with
`data-r="zoom-down | zoom-up | zoom-out | zoom-in | zoom-tl | zoom-tr | zoom-bl | zoom-br"`
starts hidden and animates in (1.6s) when scrolled into view. `data-delay="300"` staggers it in ms.
Cover elements animate on page load; everything in `#inv` only starts observing after **Open** is clicked.
Corner variants only scale from their corner (no translate), so they stay inside the viewport and the
IntersectionObserver can fire. Keep it that way.

**Continuous motion classes** go on an *inner* wrapper so they don't fight the reveal transform:
`.pulse-l .pulse-r .pulse-tl .pulse-tr` (corner flowers breathing, like the sample's pulse1/pulse2),
`.sway` (hanging vines), `.bob` (characters floating), `.breathe` (wreath/medallion).
Pattern: `<div data-r="zoom-bl"><div class="pulse-l"><img …></div></div>`.
Never put `.bob`/`.sway` on an element that uses `transform: translateX(-50%)` for centring. Centre with
`left:0;right:0;margin:0 auto` instead (already done for `.oval img`, `.cd-pic img`, `.story-hero img`).

**Layout:** a single column of max 430px (`--col`). At ≥960px a fixed scenic panel `.desk` fills the
left (3 crossfading slides + names), and the invitation sits on the right, same as the sample's desktop.

### 5.2 Process the owner's zip
Raw PNGs from ChatGPT are large and may have: a white background, a **fake drawn checkerboard**,
or bits of neighbouring art. `prep_assets.py` handles all three.
```bash
mkdir -p nikah/_raw && unzip -o ~/Downloads/<their-zip>.zip -d nikah/_raw   # _raw is git-ignored
python3 nikah/tools/prep_assets.py nikah/_raw/<folder> nikah/v4/assets/new --max 1400
# wreath with a see-through middle:
python3 nikah/tools/prep_assets.py nikah/_raw/<folder> nikah/v4/assets/new --only wreath-round --holes 400
```
- Files named `bg-*` / `og-*` are treated as full-bleed backgrounds (no cut-out, long side ≤ 2000px, q80).
- Everything else becomes a trimmed transparent WebP (long side ≤ 1400px, q86).
- **Open `assets/new/_contact.png` (dark-green sheet) and check every item:** halos or white fringes,
  missing pieces (white petals or shirts eaten by the cut-out), leftover checkerboard, cropped feet.
  If white parts got eaten, the outline wasn't closed. Re-run that file with `--keep-frags`, or ask the
  owner to regenerate on a transparent background.
- Move the good files from `assets/new/` into `assets/`. Don't commit `_contact.png` or `new/`.
- Faces must match across images (beard, short wavy hair / round gold glasses). Flag any that drift
  to the owner instead of shipping them.
- Don't ship `character-sheet` or `cat-sheet`; they are references only.

**Size budget:** background ≤ ~250 KB each, cut-out ≤ ~120 KB, whole page ≤ ~3 MB.
Use `loading="lazy"` on every `<img>` below the cover/opening. Only preload cover assets.
